# PWA Installation Guide

## 📱 Installing on Android

1. Open Chrome or any Chromium-based browser
2. Navigate to the app URL
3. Tap the menu (⋮) in the top right
4. Select "Install app" or "Add to Home Screen"
5. Follow the prompts to install
6. The app will appear on your home screen like a native app

## 🍎 Installing on iOS (iPhone/iPad)

1. Open Safari browser (required for PWA on iOS)
2. Navigate to the app URL
3. Tap the Share button (square with arrow pointing up)
4. Scroll down and tap "Add to Home Screen"
5. Edit the name if desired, then tap "Add"
6. The app will appear on your home screen

## 💻 Installing on Desktop

### Chrome/Edge/Brave
1. Open the app in your browser
2. Look for the install icon (⊕) in the address bar
3. Click "Install" in the popup
4. The app will open in its own window

### Alternative method
1. Click the menu (⋮) in the top right
2. Select "Install [App Name]" or "Create shortcut"
3. Check "Open as window" for a native app experience

## ✨ Features

- **Offline Support**: Works without internet connection
- **Fast Loading**: Cached for instant access
- **Native Feel**: Runs in standalone mode
- **Auto Updates**: Automatically updates when online
- **Push Notifications**: Receive notifications (if enabled)
- **Home Screen Icon**: Quick access from your device

## 🔍 Verifying Installation

After installation:
- The app should open in fullscreen/standalone mode
- No browser UI (address bar, tabs) should be visible
- The app icon should appear in your app drawer/launcher

## 🛠️ Troubleshooting

**App not installing?**
- Ensure you're using a supported browser (Chrome, Safari, Edge)
- Check that you're accessing via HTTPS (required for PWA)
- Clear browser cache and try again

**Offline mode not working?**
- Open the app at least once while online
- Wait for "App ready for offline use" confirmation
- Check browser console for service worker errors

**iOS not showing Add to Home Screen?**
- Must use Safari browser (not Chrome/Firefox)
- Ensure you're tapping the correct share button
- Some corporate/school networks may block PWA features
